01 프로필

RunRun — 웹소켓 기반 실시간 러닝 플랫폼

2025.12 – 2026.01

멀티캠퍼스 백엔드 부트캠프 최종 프로젝트 · 5인 팀 · 담당: 채팅, 온라인 대결, 고스트 모드

오프라인 러닝(모집 기반 그룹 매칭), 온라인 대결, 고스트 러닝, 개인 트래킹, 실시간 채팅까지 지원하는 종합 소셜 러닝 플랫폼. 관계형 데이터는 PostgreSQL, 채팅 메시지는 MongoDB, 실시간 캐싱·Pub/Sub은 Redis로 나누는 폴리글랏 퍼시스턴스 구조로 설계했습니다.

주요 구현

  • WebSocket(STOMP)으로 실시간 메시지 송수신을 구현하고, Redis Pub/Sub을 메시지 브로커로 활용해 다중 서버 환경에서도 모든 사용자에게 채팅이 동기화되도록 설계
  • 실시간 GPS 트래킹 기반 온라인 대결 모드 — Haversine 공식으로 이동 거리를 계산하고 Redis ZSet으로 실시간 랭킹 관리, 참가자 타임아웃 자동 처리
  • 과거 기록과 현재 러닝을 비교하는 고스트 모드 — 선형 보간(linear interpolation)으로 페이스 비교 로직 구현
  • 채팅·랭킹·GPS 데이터를 하나의 채널 패턴 기반 Redis Pub/Sub 브로커로 통합해, 서버가 늘어나도 설정 변경 없이 확장 가능한 구조 설계

트러블슈팅

  • 완주 처리가 특정 조건에서 중복 기록되는 버그를 발견 — GPS 신호 수신, 사용자 확인, 시간 초과 처리가 동시에 완주 처리를 실행할 수 있는 구조적 결함임을 파악해 처리 순서를 재설계하고 재현 테스트로 검증

다짜고짜 — 국내 여행계획서비스

2025.10 – 2025.11

멀티캠퍼스 백엔드 부트캠프 팀 프로젝트 · 4인 팀 · 담당: 사용자 인증, 관리자 데이터 관리

한국관광공사 공공 API 기반 관광지(12,900개)·숙소(3,500개) 데이터를 통합하고, AI가 자동으로 여행 코스를 추천하는 서비스입니다.

주요 구현

  • HS512로 서명한 JWT를 Access Token(3시간) / Refresh Token(1일) 이중 구조로 발급, OncePerRequestFilter 기반 JwtFilter로 헤더·쿠키에서 토큰을 추출·검증
  • Refresh Token은 DB에 저장해 재사용/재발급을 관리하고, 로그아웃 시 삭제해 세션 무효화. 토큰 검증 실패 유형을 커스텀 예외로 구분해 401 응답 처리
  • HTTP 메서드별로 세분화한 역할 기반 접근 제어(RBAC) — 조회는 비로그인도 가능, 생성·수정·삭제는 USER/ADMIN 권한 필요, 관리자 기능은 ADMIN 전용
  • 관리자 대시보드에서 회원·관광지·숙소 데이터 CRUD, 관광지 삭제는 소프트 삭제 방식으로 데이터 유실 방지
